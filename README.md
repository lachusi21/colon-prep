# 周中凱腸胃內科診所 — 清腸衛教指引

大腸鏡檢查前的清腸衛教單頁。病人選擇「易暢淨低渣代餐」或「自主飲食控制」、
填入檢查日期後，頁面會自動排出屬於他的完整時程。

- 清腸藥：**保可淨**（分兩劑，檢查前一天 17:00 與當天 05:00）
- 代餐：**易暢淨低渣代餐**（檢查前一天四餐，16:00 前吃完）
- 檢查時段：僅上午

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 網站本體。單一檔案，無建置流程，所有 CSS 與 JS 都內嵌 |
| `mascot-a.png` `mascot-b.png` | 去背後的兩位醫師，標題區使用 |
| `thumb.png` | 1200×630 分享縮圖（og:image） |
| `icon.png` | favicon |
| `mascots.jpg` | 診所原始海報，上面兩個 png 由它裁切而來 |
| `make-mascots.ps1` | 從海報裁出人物並去背。改裡面的座標可重新取景 |
| `make-thumb.ps1` | 合成分享縮圖與 favicon |

## 重新產生圖片

PowerShell 5.1 讀取無 BOM 的 .ps1 會用 ANSI 解碼而弄壞中文字串，
所以這兩個腳本必須存成 **UTF-8 with BOM**。

```powershell
.\make-mascots.ps1
.\make-thumb.ps1
```

## 內容來源

時程、劑量與飲食限制均依診所提供的保可淨服用說明與易暢淨原廠單張撰寫。
修改前請先與診所確認，**若醫師另有指示，一律以醫師指示為準**。
